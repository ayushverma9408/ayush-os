# AYUSH OS — Developer Portfolio

A terminal-inspired portfolio for **Ayush Verma**, Computer Science undergraduate at NIT Silchar.

## Stack
- SvelteKit + Svelte 5
- TypeScript
- Vite
- Lucide icons
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run check
npm run build
```

## Project notes
This portfolio is a work in progress. Project statuses and skill groups are intentionally described conservatively; concepts and early-stage work are not presented as completed products.
